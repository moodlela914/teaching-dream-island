# teaching-dream-island｜教學夢幻島 Skill

將新教材製作成可互動的 3D 教學群島；主題風格、課程島數量、課名與順序依教材規劃，不限定萬聖節或七座島。

## 下載與安裝

- [下載完整 ZIP](./teaching-dream-island.zip)：含完整 Skill 資料夾與可直接複製的使用指令。
- [新教學夢幻島使用指令.md](./新教學夢幻島使用指令.md)：修改素材路徑後，整段貼入 Codex。
- [Skill 說明](./teaching-dream-island/SKILL.md)：完整建置、內容與驗收契約。

解壓縮後，將 `teaching-dream-island` 資料夾放進 Codex 的 skills 目錄，例如 Windows 的 `%USERPROFILE%\.codex\skills\teaching-dream-island`。使用指令檔留在方便複製的位置即可。若已存在同名 Skill，先備份舊版本再更新。檔案內的 Windows 素材路徑只是範例，換電腦後請改為該電腦實際路徑。

## 素材放哪裡

每個新專案使用獨立素材資料夾，可包含 Word、PDF、簡報、Markdown、圖片、音樂及資源連結清單，不必手工整理 JSON。範例：`C:\AgentFiles\新的教學夢幻島\materials`。原始素材與網站輸出分開，不放入 Skill 的範本資料夾。

## 主要功能

- 各島同名資料夾中的 Markdown 教材為單一來源，同步 JSON 快取、導覽及完整文字備援。
- 點島先聚焦，點建築讀教材；中央島可進入旋轉觀看的 3D 備課室，點島主焰兒開教材，轉身點門返回外觀。
- 單段平滑全景、滑鼠滾輪自由縮放（含島名標籤上）、可收合導覽清單。
- 14 位具名概念島民、各島島主、不同橋型、海景、日夜、主題裝飾、減少動態與音樂音量。
- 每課測驗、跨課總複習、瀏覽器進度及 JSON 匯入匯出。
- 全部課程已讀且各課測驗達 75% 可製作 PNG 學習完成紀念證書；附框線、紀念鋼印與當日日期，非官方認證，無學習單前置條件。

## 建置與測試環境

需要可執行的 Python 3 與 Node.js；瀏覽器測試另需 Playwright 及 Chromium。Three.js 與必要控制模組隨範本附帶；保留 `vendor/THREE-LICENSE.txt`。Skill 的示意教材須依新素材完整替換，不能直接當作正式教學內容交付。各種新主題及島數仍須依驗收清單實測。

## 發布流程

**先完成本機建置與桌機／手機驗收，讓使用者確認成果；只有使用者主動提出本次發布要求後才部署。** 不沿用過往網站的發布授權，也不因本 repo 已公開就自動發布新教材網站。本 repo 保存 Skill 與使用指令，不是已部署的教學網站。
