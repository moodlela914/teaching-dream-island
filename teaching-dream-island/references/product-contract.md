# 成果契約

本文件是未另行修改時的功能預設。使用者明確的新要求優先；把差異寫入新專案規格。網站名稱預設「教學夢幻島」，可使用使用者指定的「紅焰教學夢幻島」或新主題名稱；不沿用舊教材作者身分作新教材背書。

焰兒是此技能可直接沿用的虛構導覽角色，不等於新教材的真人講師。沒有新角色要求就沿用焰兒，不必反覆詢問；使用者另指定島主時，同步更新3D角色、頁首文字、FAQ與操作說明。若素材不足以支持14個不同概念，列入資料問題，不能湊造知識。

| 範圍 | 可驗收行為 |
| --- | --- |
| 中央島 | 全站介紹、使用者提供的講師資訊與肖像、各課輪抽總複習、進度與紀念證書；主島最大，周邊島各有獨特地標；點中央島聚焦，再點主建築進入可旋轉的室內，家具與走動焰兒可見。點室內焰兒才開教材；關閉教材仍在室內，轉身點門回外觀 |
| 課程島 | 依教材概念、章節與目標決定N，無固定3–7課限制；含中央島總數為N+1。依核准數量、課名、順序；完整章節、學習目標、提示詞／操作／比較表（素材有才加入）、全部原稿資源連結 |
| 教材連結 | 簡報、Gem、Skill 工作台、表單、下載等都納入素材盤點；逐一核對數量和網址，新分頁開啟；登入／效期限制實際測試並說明 |
| 兩段式互動 | 點島名或島面先聚焦放大，**不開燈箱**；再點真正 3D 主建築或「教材」提示才開詳細資料。關閉後留在該島；中央島草地也不可當建築 |
| Markdown 教材 | 每座島包含中央島皆有 `site/islands/<島名>/教材.md`；依 manifest 指定順序由共用解析器載入，增刪正文後同步 JSON 與文字備援。錯誤要指出檔案／分區，不回寫或覆蓋使用者修改；編輯即時影響本機預覽，正式站須由使用者另行提出發布 |
| 導覽清單 | 左側整欄可收合／恢復，畫布隨可用區域最大化；可展開各島章節、搜尋、直達內容或測驗；分類只導覽，不更改課名與順序。不操作 3D 也能讀完教材、測驗與領證 |
| 地形 | 不是整齊等距圓環；每島大小、高度有明顯差異，高起主島與周邊大小島；聚焦後建築與角色可清楚點選；島名縮小置於各島正上方，不用引導線，不遮建築 |
| 橋梁 | 每座有不同造型（例如繩索、石拱、糖果階梯、廊橋、圓木、藤蔓、水晶、石階、齒輪）；橋兩端接島面，岸內平坦，離岸才升降；斜坡、階梯、扶手與路徑一致 |
| 人物 | 預設 14 位不同外觀的具名島民，頭頂提示可點；每人一個不重複、來自本教材的關鍵概念，附對應章節入口；沿相連島間步道與橋自由行走，不能穿建築、漂浮、掉入海面 |
| 島主 | 每島含中央島均有焰兒行走身影，隨時可點問功能與教材；全景收起人物提示，聚焦才顯示附近可點人物，移入／焦點時暫停以利操作 |
| 說明與控制列 | 焰兒圖與「我是島主焰兒，在島上遇到我，我會隨時回答你問題喔！」收進右上「？」操作說明，圖文本身不做連結或按鈕，不占主畫面。真正問答入口在島上人物；控制列置頂，右上「控制列」可顯示／隱藏並記住偏好 |
| 海景與角色造型 | 海上水波與數艘避島航行船隻，遠景陸地、不同樹木與山脈、空中雲；中央建築有燈塔掃光。人物為原創可愛日系動漫Q版、大眼睛、不同髮型及衣著；所有場景動態尊重減少動態 |
| 問答範圍 | 預設純前端 FAQ＋本站教材檢索，附課程來源，不需要 API 金鑰；找不到就坦白說明、不編造、不直接洩漏測驗答案。明確教材詞優先於「流程／儲存」等泛用功能詞 |
| 隨堂評量 | 每課 4 題選擇題＋逐題解析，標「自編練習題」；選項順序可洗牌但以穩定 ID 判分；缺答提示，不把未完成作答計入最高分；可重試 |
| 總複習 | 每輪依課程順序各抽一題，共 N 題；下一輪換題。N 必須取實際課數，不寫死 7；總複習不代替各課證書條件 |
| 證書 | 全部課程已讀，且各課最高分至少 75%，即可輸入姓名下載 PNG／列印存 PDF「學習完成紀念證書」。原創巴洛克框線、當日日期及紀念鋼印；站名、作者、課數與鋼印依新站資料，不帶舊作者認證。本機紀念，非官方認證；**不需要學習單** |
| 進度 | 姓名、已讀、最高分與偏好只存在訪客瀏覽器；不同網站用不同儲存命名空間。JSON 可匯出／匯入，合併已讀、保留最高分與現有姓名，不覆蓋偏好；拒絕外站、題庫不符及損毀檔，不污染既有進度。重載保留、可確認後重置；儲存被拒要告知僅本次有效 |
| 視覺 | 主題依素材與核准偏好，可自然、海洋、星際、文學、歷史、童話、四季或自訂，萬聖節僅可選範例。柔和明亮低多邊形；主題相符的裝飾與動態物件不妨礙教材與人物；三底色、獨立白天／黃昏／夜晚，偏好保留 |
| 動態聲音 | 滑鼠旋轉／滾輪及觸控雙指縮放；回全景以單段平滑過場直接抵達預先算好的最佳大小，不二次跳動，重按不彈跳。全景後滾輪仍自由縮放且不回彈，輸入可中斷過場；減少動態暫停角色、主題動態物件與場景動畫；音樂手動開始與關閉，支援音量調整與記憶，不自動播放。可使用核准音樂素材，未提供時用合成音樂 |
| 品質 | 1440×900、768×1024、375×812與橫向皆可用；44px觸控、文字對比、鍵盤焦點、Esc；無橫向溢出，標籤不碰撞、不裁切 |
| 備援 | WebGL 失敗仍有清單與互動評量；無 JavaScript 有 content.html 完整文字。無 PWA、Web App Manifest、service worker；教材用 manifest.json 是內容索引，不是 PWA |
| 發布 | 純靜態相對路徑，可部署 GitHub Pages 子目錄；先本機確認，等使用者主動提出本次發布才部署，歷史授權不自動沿用。僅 site/（含核准公開的 Markdown 教材），不發布 materials/ 原始素材、工作檔、私人資料、憑證或測試。需要登入由使用者在可信介面操作 |

原有教材若談「開放題／學習單」屬知識內容可保留；不要重建網站學習單表單、存檔或證書前置條件。外部 AI 與跨裝置帳號屬新需求，須另定後端與授權，不能把金鑰放進靜態前端。
